# Risk register: Northwind support intelligence

Mapped to the twelve generative AI risks of NIST AI 600-1, "Artificial Intelligence Risk
Management Framework: Generative Artificial Intelligence Profile" (July 2024), section 2. Each
row names an owner (a lifecycle role from `python -m nw.agent.catalog --roles`), the controls
with the file that implements them, the evidence a reviewer can run, and what is left.

Scale: likelihood and impact 1 (low) to 3 (high), for a real deployment of this system.
Reviewed 2026-09-30. Review with every release that changes a model, a tool or a data class.

## How this register is used

- A new use case in `data/use_cases.yaml` is read against every row before it is approved.
- A gate failure, a guardrail spike, a drift alarm or an incident updates the row it touches.
- Rows with a high residual are listed in the release notes until they drop.
